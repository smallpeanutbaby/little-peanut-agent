# Agent IDE 项目文档

本文档集用于定义一个“类 Codex”的多 Agent 开发平台第一版范围。第一版即覆盖以下核心能力：

- 内嵌浏览器与自动化测试
- AI 编写/修改代码
- 多项目工作区开发
- Agent 对接 Agent
- 后端项目对接前端项目

文档清单：

1. [产品需求文档 PRD](./01-产品需求文档-PRD.md)
2. [系统架构设计与模块拆分清单](./02-系统架构设计与模块拆分.md)
3. [Codex 风格分层规划](./03-Codex风格分层规划.md)

建议阅读顺序：

1. 先看 PRD，确认功能范围与验收标准
2. 再看架构文档，确认技术实现路径与模块边界
3. 再看分层规划，固定桌面端、本地运行时、Agent、浏览器、SQLite 的边界
4. 最后按模块拆分清单创建开发任务
