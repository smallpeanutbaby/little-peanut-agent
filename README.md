# little-peanut-agent

`little-peanut-agent` 是一个桌面端 Agent IDE 原型项目，当前仓库包含应用源码与第一版产品文档。

## 目录结构

- `src/`: Electron + React + TypeScript 应用源码
- `doc/`: 产品需求、架构设计、分层规划等项目文档

## 本地开发

```bash
cd src
npm install
npm run dev
```

## 构建

```bash
cd src
npm run build
```
